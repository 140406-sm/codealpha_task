TASK 1:
E20 Petrol Data Visualization

Project Overview:
This project focuses on visualizing an E20 Petrol dataset to understand patterns, trends, and relationships within the data.
The project was completed as part of my **Code Alpha Data Analytics Internship**.

## Objective
The main objective of this project is to analyze the E20 Petrol dataset through different data visualization techniques and present meaningful insights in an easy-to-understand way.

Tools & Technologies Used:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Dataset:
The project uses an E20 Petrol dataset containing 600 rows of data.
The dataset was analyzed and visualized using Python.

Visualization Techniques:
The following visualization techniques were used:
- Bar Charts
- Line Charts
- Histograms
- Box Plots
- Scatter Plots
- Heatmaps
- Distribution Plots

Project Workflow:
1. Imported the dataset
2. Loaded and explored the data
3. Checked the structure and data types
4. Performed basic data cleaning
5. Created different visualizations
6. Analyzed patterns and relationships
7. Generated meaningful insights from the visualizations

Key Insights:
The visualizations helped identify important patterns, distributions, trends, and relationships within the E20 Petrol dataset.
These visual representations make the data easier to understand and support better interpretation of the dataset.

The main analysis and visualization work is available in:
`E20_Petrol_Visualization.ipynb'
